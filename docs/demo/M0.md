# M0 Foundation — demo note

- `pip install -e .` then `system-budget-studio` opens an empty, IBM Plex / Carbon-styled window; `budget --version` prints the version.
- `pip install -e ".[dev]"` then `pytest`: 8 tests (CLI, GUI window and bundled fonts, runtime-vs-dev dependency separation, offline guard with a negative test).
- Offline guard: fresh interpreter, `socket.connect`/`getaddrinfo` blocked, asserts no networking module (`http.client`, `ssl`, `urllib.request`, `requests`, `PySide6.QtNetwork`, ...) is imported by core, CLI or GUI start-up.
- Lock files with hashes: `packaging/lock.sh`; CI installs from `requirements-dev.lock`.
- Packaging: `packaging/build.sh` (PyInstaller one-folder, CycloneDX SBOM, licence report; dev extra only). Linux bundle verified to start; Windows is built by the tag workflow and not yet verified.

Not yet done: installer wrapper (no-admin Windows installer) and RHEL 8 glibc check — tracked for M6 hardening, portable one-folder bundle covers M0.
