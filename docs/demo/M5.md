# M5 Link budget — demo note

```
budget export-examples demo
budget run demo/microsat_150kg --budget link --out out        # static link table
budget link-passes demo/microsat_150kg --out out              # margin, rate and data volume over every pass
system-budget-studio demo/microsat_150kg                      # tabs "Link budget" and "Link passes"
```

`microsat_150kg` has two links with **invented** values (S-band telemetry downlink and X-band payload downlink; their source text says so, as do the invented Eb/N0 and attenuation tables). `cubesat_3u_eps` has one complete invented UHF downlink; `cubesat_3u` has the same link as a template whose numbers are `TBD`, so its results show **n/a** with a `RESULT_INCOMPLETE` entry for each missing input (never a zero).

What you see for the microsatellite: the static table (EIRP, G/T, free-space and atmospheric loss, C/N0 at each chosen elevation and range, the highest listed rate that closes and the rate at which the margin equals the requirement), the margin at every listed rate, and over the scenario's 15 passes the margin per rate with the required margin, the selected data rate (it changes with elevation: the X-band link drops from 50 Mbit/s overhead to 10 Mbit/s near 10 degrees), the elevation, a table of passes and the data volume per pass and per day (the link counts only while the spacecraft is in its downlink mode). Selecting a pass row zooms the plot; the cursor shows every value and the mode.

Inputs: `links/<id>.yaml` (format in `docs/FILE_FORMAT.md`): antenna as constant gain, pattern table or CSV pattern file (spacecraft angle from nadir), receiver G/T given or built from antenna, noise temperature and feed loss, modulation and coding looked up in `config/ebn0_table.yaml`, named attenuations from `config/attenuation_table.yaml`, active modes, tracking limit, static points. G/T uses the new `_dbk` suffix.

Verified against hand calculations (19 regression cases): free-space loss of the textbook 2 GHz / 1000 km case (158.47 dB), the Boltzmann constant in dB, EIRP, G/T, C/N0 and Eb/N0 of a worked link, the rate at which the margin equals the requirement, nadir-angle geometry, table interpolation, attenuation interpolation, a spacecraft pattern at 30 degrees elevation, an uplink with a receive pattern, placeholders giving n/a, pass volumes (exact for passes that start between samples), a longer range lowering the selected rate, active modes, the tracking limit, pattern files. Hypothesis properties: more range, a higher data rate or more loss never increases the margin; more transmit power never decreases it.
